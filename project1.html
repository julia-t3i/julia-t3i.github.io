FairyTale iOS App

FairyTale is an iOS app built with SwiftUI that allows users to create their own interactive storybooks. Users can drag and drop characters, backgrounds, props, and text onto pages, upload their own assets, and build stories page by page. All music, illustrations, and UI elements are originally created by me.
